## Project Highlights

- Windows Server and Hyper-V migration to Azure VMs
- Citrix to Azure Virtual Desktop migration design
- Hybrid networking using site-to-site VPN
- Microsoft Entra ID and hybrid Active Directory
- Azure Files and Azure File Sync
- Azure Backup, disaster recovery and monitoring
- Terraform infrastructure-as-code examples
- PowerShell infrastructure automation

## 2026 Architecture Principles

Security by design, least-privilege access, infrastructure as code, high availability, observability and cost optimization.
